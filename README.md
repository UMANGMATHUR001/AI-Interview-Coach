# 🚀 AI Interview Practice Chat

An AI-powered mock interview platform designed to simulate real technical interviews with interactive conversations, personalized feedback, performance analytics, and secure authentication.

Built to help users practice coding, DSA, frontend, backend, HR, and system design interviews in a modern AI-driven environment.

---

## ✨ Features

* 🔐 OTP-based Authentication System
* 🤖 AI-Powered Interview Simulation
* 💬 Real-Time Interactive Chat UI
* 📊 Performance Analytics Dashboard
* 📈 Topic-wise Score Tracking
* 🧠 AI Feedback & Improvement Suggestions
* 🗂 Interview Session History
* ⚡ Smooth Animations & Modern UI
* 📱 Fully Responsive Design
* 🔒 JWT Session Authentication

---

## 🛠 Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Framer Motion

### Backend

* Node.js
* Express.js

### Database

* SQLite

### Authentication

* OTP Verification
* JWT Authentication

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repo-link>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
